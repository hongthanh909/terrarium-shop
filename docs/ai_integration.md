# AI Recommendation Integration

## Overview

The Terrarium Shop now includes an AI recommendation endpoint that leverages the **Ollama** `llama3:8b` model. The AI receives real product data from the database and generates suggestions, care instructions, and warranty information.

## Files Added / Modified

- **`apps/web/lib/rateLimiter.ts`** – In‑memory IP‑based rate limiter (used by the AI endpoint).
- **`apps/web/lib/aiPrompt.ts`** – Helper to build a prompt containing product details.
- **`apps/web/app/api/ai/recommend/route.ts`** – New API route (`POST /api/ai/recommend`).
- **`fixall.md`** – Updated with information about the AI integration.

## Endpoint Details

- **URL**: `/api/ai/recommend`
- **Method**: `POST`
- **Body**:
  ```json
  { "productId": "<product-id>" }
  ```
- **Rate Limiting**: 10 requests per minute per IP.
- **Response** (JSON):
  ```json
  { "recommendation": "<markdown>" }
  ```
  On error you will receive an `error` field with a message and appropriate HTTP status code.

## Usage Example

```bash
curl -X POST http://localhost:3000/api/ai/recommend \
  -H "Content-Type: application/json" \
  -d '{"productId":"12345"}'
```

The response will contain markdown with:
- Suggested complementary products.
- Care instructions.
- Warranty advice.

## How It Works

1. **Rate limit** – Prevents abuse from a single IP.
2. **Product fetch** – Retrieves product details via Prisma singleton.
3. **Prompt generation** – `buildProductPrompt` creates a system prompt containing a concise list of product attributes.
4. **Ollama call** – Sends the prompt to the local Ollama server (`http://localhost:11434/api/generate`).
5. **Result** – Returns the generated markdown to the client.

## Notes

- The AI model only uses product data; no trend information is required.
- Ensure Ollama is running and accessible at `http://localhost:11434`.
- The endpoint returns a fallback error if Ollama is unreachable.
